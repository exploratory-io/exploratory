# ノート・アナリティクスを作るときの製品の使い方

## 分析

結論がモデル（回帰・分類・クラスタリングなど）に頼っているときは、同じモデルを Exploratory のアナリティクスでも作る。出力は get_analytics_template の出力一覧から選ぶ。予測モデル（回帰・分類。出力一覧に feature_importance_bar があるもの）は、変数重要度（feature_importance_bar）で効く項目の順位を示し、影響度（local_importance_ で始まる出力）で主な項目の値が変わると目的変数がどう変わるかを示す出力をノートに入れる。重要度の図は変数重要度の 1 つだけにする。元が別の方法（相対ウェイト、R² の内訳、標準化係数の大きさなど）で重要度を出していても lmg_bar などを足さず、元の重要度の図をこれで置き換え、報告に書く。クラスタリング（K-means など。出力一覧に radar で始まる出力があるもの）は、レーダーでグループの特徴を示す出力を入れる。これらは元の成果物に同じ図が無くても入れる。足した図の説明は、get_analytics_template の出力一覧の shows から書く。get_analytics でその出力の値を読み、順位や大きさがノートの中のほかの図や表（係数など）と違って見えるときは、測り方の違いを 1 文で書く。元の成果物との違い（置き換えた指標など）は本文に書かず、最後の返答で利用者に伝える。ほかのアナリティクスは、出力一覧の question と shows を読み、問いに合う出力を選ぶ。「変数重要度」「影響度」は Exploratory の出力と同じ意味でだけ使い、係数は「係数」と呼ぶ。クラスタに名前を付けるときは、名前の付け替えを加工で行う。

アナリティクスの出力で変えられる表示は、get_analytics_template の outputs[].settings にある設定（点のラベルなど一部の出力だけ）で、色・値のラベル・桁・項目名を変える設定は無い。項目名は列名がそのまま出るので、接頭辞付きなどで読みにくい列は create_analytics の前に rename で短くする。元の図が色分け（例: 1 項目だけ別の色）・% のラベル・決まった桁で意味を示しているときは、その出力を save_result_as_dataframe（analyticsId と outputId）で表にし、bar や table で作り直して元の色・ラベル・桁に合わせる（色は axes.color と highlightValues、% は 0〜1 の列に yAxisNumberFormatting: "percentage"）。変数重要度・影響度の出力は、それとは別にそのまま入れる。

回帰・相関・クラスタリングなど、アナリティクスのテンプレートがある計算はアナリティクスで作り、その出力を save_result_as_dataframe で表にしてから図にする（R で係数や距離を計算し直さない）。分析で作る区分の列（クラスタ、グループ分けなど）は、アナリティクスの「データ」の出力を save_result_as_dataframe でデータとして保存し、そのデータから作る。元の成果物を作り直すときは、同じ設定（変数・標準化・乱数の種・試行回数・欠損の扱い）で作り、区分の番号が元と入れ替わっていれば、名前の付け替えで元にそろえる。

元の数字カードは Number にし、ノートでは ::::columns で横に並べる。
