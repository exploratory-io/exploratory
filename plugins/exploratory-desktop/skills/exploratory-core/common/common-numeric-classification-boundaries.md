"common-numeric-classification-boundaries"

## version

## kind

"common"

## title

"数値の分類方式と明示された境界・母集団を保持する"

## applies_when

[
  "数値列を下位・上位の分位点、平均からの標準偏差、またはIQRの境界で分類したい依頼"
]

## rules

[
  "自然な依頼文で明示された分類方式・割合・閾値・比較・対象列・母集団を優先する。分位点方式、標準偏差方式、IQR方式を互いに置き換えない。外れ値という語だけで方式や閾値を決められないときは、作り方を決める前に確認する",
  "下位p%の境界は対象母集団の分位点p/100、上位q%の境界は分位点1-q/100。pとqは独立に指定された割合を使う。下位50%・上位50%なら両方が同じ中央値になる。箱の四分位点25%・75%へ読み替えない",
  "割合は0%から100%の範囲で解釈する。指定から下側の境界が上側の境界を超える等、分類条件が両立しないときは、比較の順番や既定値で意味を補わず確認する",
  "平均からk標準偏差を超える値という方式なら、同じ対象列・同じ母集団の平均から、依頼された側だけにk標準偏差の境界を使う。両側が指定された場合は下へk標準偏差、上へk標準偏差とし、片側の依頼へ反対側の境界を補わない。指定kを別の倍率や分位点へ変更しない。標準偏差の定義は利用する設定・実行経路の契約と照合する",
  "IQR方式が明示されたときだけ、その母集団の第1・第3四分位点とIQRを用いる。IQRに掛ける係数が明示されていれば保持する。分類用の係数を、別のチャート描画の既定値から勝手に補わない",
  "境界より低い・より高い、境界以下・以上など依頼が指定した比較をそのまま使う。境界と等しい値の扱いを反転させない。比較や欠損の扱いが必要なのに依頼・利用する経路の契約から決められない場合は確認する。依頼の明示指定または利用する経路の契約なしに、欠損値を0や任意の数値へ置き換えない",
  "全体の値から境界を求める依頼では、色分けや繰り返しごとに境界を再計算しない。グループ別の依頼では指定されたグループ内で計算する。集計点の値を母集団にする依頼と、生の各行を母集団にする依頼を区別する。集計後の点へ元行数の重みを勝手に追加しない",
  "分類する列と描画する数値列を区別する。別列を分類してX軸・色・繰り返しへ使うことと、箱ヒゲ図やバイオリン図が描画列に適用する外れ値処理は別の判断である。描画列のIQR処理を分類対象列へ転用しない",
  "設定で実現するときは利用できる方式・型・単位・有効化条件を実際の設定説明で確認する。分類列を加工する必要があるときも同じ明示方式・境界・母集団を保持し、元列の上書きが明示された場合を除き、元列を上書きしない。方法の違いだけで依頼の意味を変えない"
]

## does_not_apply_when

[
  "数値の分位点・標準偏差・IQRによる分類を求めていない依頼",
  "最小値から最大値までの等間隔区間、カテゴリの上位N、日付区切り等を求めた依頼。これらを分位点分類へ変更しない",
  "描画する数値列の箱・ヒゲ・外れ値点・密度だけを変更したい依頼。別の分類列を作る条件を補わない"
]

## in_exploratory

[
  "分類に対応するチャートの方式・設定を調べ、説明された単位と依存条件に従う。設定で足りる場合は加工を増やさない",
  "加工が必要な場合の分位点計算は、下位p%にquantile(x, p / 100)、上位q%にquantile(x, 1 - q / 100)を使う。xは依頼が指定した対象列と母集団であり、描画列とは限らない"
]
