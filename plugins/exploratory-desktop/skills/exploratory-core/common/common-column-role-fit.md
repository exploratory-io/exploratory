## id

"common-column-role-fit"

## version

1

## kind

"common"

## title

"列の意味が、割り当てる枠の役割と合うか作る前に確かめる"

## applies_when

[
  "依頼された列を、統計的な役割を持つ枠（誤差の範囲、サンプルサイズ、分母、重み、トレンドの説明変数など）に割り当てるとき"
]

## rules

[
  "列の意味が、割り当てる枠が求める役割（ばらつき・件数・母数など）を表しているか確かめてから作る。識別子・年・単なる量を役割の違う枠に置くと、集計しても意味のある答えにならない",
  "列の型（連続量・区分・識別子）が枠に合うかも確かめる。合わないと判断したら、作る前に別の列・別の図を提案する"
]

## does_not_apply_when

[
  "役割を持たない表示用の枠（色・ラベルなど）に列を置くとき"
]
