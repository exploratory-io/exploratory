## id

"common-chart-type-fidelity"

## version

2

## kind

"common"

## title

"依頼された図の種類（画面の正式名称）を読み替えない"

## applies_when

[
  "依頼文が図の種類を明示している（「テーブル」「集計テーブル」「ピボット」「クロス集計」等）依頼",
  "区分の数が多い・見た目が近い等の理由で、依頼と違う marker に替えたくなる場面"
]

## rules

[
  "依頼文にある図の種類の語（テーブル→table、集計テーブル→summarytable、ピボット/クロス集計→pivot 等）と、実際に指定する marker を一致させる。見た目が近い・区分数が多い等の理由で、依頼と違う marker に勝手に読み替えない。図の種類の語がある依頼を、加工ステップでデータを整えただけで終えない。列の値の変換・列の選び方も、その図の枠と func で作る",
  "クロス集計はピボット（pivot）を使う。区分の数が多くても、ヒートマップなど別の図に置き換えない（利用者の指示 2026-09-28）"
]

## does_not_apply_when

[
  "依頼文が図の種類を明示せず、目的（比較・構成・推移等）だけを伝えているとき（この場合は目的に合う種類を選んでよい）"
]
