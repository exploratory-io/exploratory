## id

"common-multi-value-as-array"

## version

1

## kind

"common"

## title

"2 つ以上の値は 1 つのチャートに配列で置く"

## applies_when

[
  "複数の指標（列）を同じ図で比べたい依頼、特に系列ごとに異なる計算（構成比・累積等）を求める依頼"
]

## rules

[
  "複数の指標を比べたい依頼は、指標ごとに別々の図を作るのではなく、y（や meas 等の複数値を取る軸）に複数の {column, func} を配列で渡して 1 つの図にまとめる。まとめる指定（「1つのグラフで」等）があるときは特に、別々の図に分けない",
  "系列（2 本目以降）だけに異なる計算（構成比・累積・移動平均等）をかけたいときは、その系列の番号（0 始まり。2 本目なら 1）を付けた設定名を使う。番号を付けない設定は全系列共通の計算になる"
]

## does_not_apply_when

[
  "比べたい指標が 1 つだけ、または指標ごとに軸の単位が大きく異なり同じ図で並べると読みにくいとき"
]

## in_exploratory

[
  "y は配列で複数の {column, func} を渡せる。系列ごとに異なる計算をかけたいときは番号付きの設定（例: y1WindowFunc, y1WindowFuncDirection）を使う。番号なしの設定（yWindowFunc, yWindowFuncDirection）は全系列共通になる"
]
