## id

"common-analytics-settings-before-workaround"

## version

5

## kind

"common"

## title

"分析の設定で表せる依頼は、加工や列の選び直しより先にその設定を使う"

## applies_when

[
  "依頼の条件（カテゴリのまとめ方、対象から外す列の決め方、件数・行数の上限など）が、分析の設定で表せるかもしれない依頼",
  "分析の計算に使う行だけを無作為に N 行に減らしたい依頼（「N 行を超えるときは N 行だけで計算」等）"
]

## rules

[
  "Exploratory でできることは Exploratory（チャート・アナリティクスの設定、製品の加工コマンド）で作る。できないものだけ、ステップのカスタム R コマンド（exp_custom）かカスタムチャート（R）で作る。分析の設定で表せる条件は設定で渡し、表せないときだけ加工かカスタム R で作る",
  "依頼が枠に入れる列を名指ししたときは、その列をそのまま枠に渡し、加工で作った別の列に差し替えたり枠から外したりしない。依頼の条件（値のまとめ方・対象の列の外し方・件数の数え方）は、get_analytics_template の設定（説明に同じ動きが書かれたもの）で表せるかを先に確かめ、表せるならその設定を create_analytics に渡す。カテゴリ数が指定値を超える説明列を外す条件も、列を自分で減らさず、指定値を設定に渡して製品に判定させる。加工ステップの結果にこの知識が付き、その加工が設定で表せるときは、delete_wrangling_step で消してから設定で作る",
  "分析に使う行だけを無作為に減らす依頼は、分析の設定 takeSample \"TRUE\" と max_nrow で行い、データフレームに行を抜き出すステップ（sample_rows 等）を足さない（同じデータを使うほかの分析・チャートの結果も変わるため）",
  "依頼にない任意の設定は質問せずに省略し、製品の既定のまま create_analytics で作成する。判定方法だけを指定したときも、設定の説明がしきい値の省略を認めていれば、上下限や数値を質問して止まらず、しきい値を省略して作成する"
]

## does_not_apply_when

[
  "依頼がデータフレームそのものの加工（列を作って残す・行を抜き出して残す）を求めるとき",
  "分析の設定のどれも依頼の条件を表せないとき"
]

## in_exploratory

[
  "get_analytics_template の settings（例: 上位 N 以外を「その他」にまとめる設定、カテゴリ数が多い列を対象から外す設定）",
  "分析の設定 takeSample（画面の「データをサンプルする」）と max_nrow（その隣の行数の欄）"
]
